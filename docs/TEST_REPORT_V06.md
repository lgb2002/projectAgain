# v0.6 테스트 및 배포 전 체크리스트

## 수행한 검증

- GitHub/ZIP 추가 테스트 7개 통과: 정적 분석·비공개 staging·교차 계정 접근 거부·권리 확인·GitHub pinned-commit·OAuth state 검증·토큰 암호화·비공개 소스 보고서 비노출·staging 정리.
- 기존 에이전트 작업 승인 테스트 9개 통과.
- 기존 검사 권한/통합 테스트 9개 통과.
- 기존 파일 및 거래 워크플로의 통과 항목들을 그룹별로 확인. 전체를 한 번에 실행한 작업은 실행 환경에서 타임아웃했으므로 단일 배치 전체 성공으로 표현하지 않음.
- 신규 Alembic 0004까지 깨끗한 SQLite DB에서 마이그레이션 성공.
- Python compileall 성공. 신규 JSX/TypeScript 파일 구문 변환 검사 성공.

## 미검증 및 배포 환경 필요

- `npm ci && npm run build`의 실제 정식 프론트 빌드: 현 실행 환경의 npm 패키지 설치가 지연되어 완료되지 않음. Replit에서 **반드시** 실제 빌드 재검증 필요.
- 실제 GitHub App 사용자 OAuth, 설치·선택 저장소·비공개 저장소 ZIP 다운로드: 서버 인증 정보가 없어 실 GitHub 연결 통합 테스트는 수행하지 않음. API는 모의 응답으로 기능 흐름을 검사함.
- 운영용 PostgreSQL / Replit App Storage / ClamAV 연동 및 HTTPS 쿠키 동작, 대용량 파일 부하, 다중 요청의 경합 검증은 운영 환경에서 필수.
- GitHub App 권한 철회 webhook 실시간 반영, 대규모 저장소·LFS·submodule의 완전 인수 지원, 실제 코드 동적 테스트/보안 인증·지식재산권 확인 및 결제는 이번 버전 범위 밖임.

## 사용자 수동 점검

1. 기존 PostgreSQL 백업하고 `alembic upgrade head` 실행
2. 프론트 실 빌드와 새 등록 화면 표시 확인
3. 로그인 → 공개 저장소 분석과 ZIP 분석 모두 확인
4. 판매자만 비공개 원본/파일 목록 접근 가능 확인
5. 관리자 매물 검토 → 승인 → 상세 기술 요약 확인
6. GitHub App 등록 후 비공개 저장소 연결·설치·권한 해제 흐름 확인
7. 운영 ClamAV 또는 별도 검사 서버 없으면 비공개 원본 승인 불가 상태 확인
