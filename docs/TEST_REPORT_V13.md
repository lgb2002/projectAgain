- 외부 AI 에이전트 실연동 및 브라우저 종단간 사용자 흐름 미검증.

## 보안 경계

- 업로드 ZIP/저장소 원본을 플랫폼 서버에서 실행하지 않음.
- GitHub Actions CI는 외부 플랫폼이 기록한 SHA 기준 관측값. 신뢰성·재현성·라이선스 및 실제 인수 가능성을 보증하지 않음.
- 삭제 시 기술식별자와 최소한의 비식별화 DEMO 기록을 유지하며, 이미 존재하는 백업·외부 계정은 자동 파기 불가.
- 탈퇴 시 과거 CI 로그, 외부 GitHub 앱 권한, 백업의 파기 완료는 주장하지 않음.
