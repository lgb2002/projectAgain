## 미검증 및 주의

- 전체 테스트를 하나의 프로세스로 묶은 실행은 일부 이전 테스트에서 비정상적으로 장시간 정체되어, 그룹별 결과로 확인했다. 이 보고서를 전체 통합 테스트 성공으로 해석하면 안 된다.
- npm 의존성 설치가 불완전해 React 공식 `npm run build`는 아직 완료하지 못함 (`vite/client` 타입 없음). Replit에서 소스 반영 후 반드시 정상 빌드해야 한다.
- 운영 PostgreSQL 데이터베이스, 실제 브라우저 UX, Replit App Storage, 실제 GitHub OAuth/SMTP 환경은 이 로컬 검증과 별개로 E2E 점검해야 한다.
- 전자서명 제공자, PG·에스크로·정산 사업자, 법적 저작권 이전은 의도적으로 연결하지 않았다.
