# ProjectAgain v0.10 — UX 안정화 및 일관성 개선

기준 버전: v0.9 (`projectagain_v09_development_roadmap.zip`)

## 범위

이번 버전은 매물 등록·검색·상세·내 활동·거래·관리 화면에 집중한 UI/UX 개편입니다. 플랫폼 API 계약과 DB 테이블 구조는 v0.9와 동일합니다. 시연 거래라는 정책, 매물 승인, 비공개 파일 접근 정책을 변경하지 않았습니다.

## 이전 평가의 심각한 문제 10개 대응

1. **작성 데이터 손실** — 새 등록·수정 화면(`ListingEditorUX.tsx`)에 계정별·매물별 브라우저 자동 임시저장(600ms), 새로고침 복구, 수동 삭제, 저장 완료 시 삭제, 나가기 전 경고를 추가했습니다. 서버에 더 최신 매물이 있을 때 오래된 브라우저 임시본을 자동 적용하지 않습니다. GitHub/ZIP 분석의 **원본 연결은 새로고침 이후 재확인**하도록 합니다.
2. **단계별 검증** — 이름·설명(30자)·가격·포함 자산·비용·기간·판매 권리 확인을 각 단계에서 검사하고, 잘못된 단계 이동을 막습니다. 마지막 단계에서 실제 구매자용 핵심 내용 미리보기를 표시합니다.
3. **거래 단계 불명확** — 계약 확인 → 자료 인계 → 구매자 검수 → 시연 완료의 단계 표시 및 거래 상태별 다음 행동 안내를 추가했습니다. 분쟁·취소는 별도 상태로 안내합니다.
4. **구매 결정 정보 분산** — 매물 상세 상단에 포함 자산, 추가 작업·결함, 외부 서비스, 검증 상태를 요약하고 구체적 항목으로 이동하는 탐색 링크를 넣었습니다. 정적 분석 자료가 없는 경우에도 공백 대신 미등록 상태를 표시합니다.
5. **관리 영역 중복** — 사용자가 자주 찾는 내 활동, 비공개 자료, 에이전트 연결의 진입 위치를 정리했습니다. 대시보드의 중복 에이전트 권한 발급 UI와 중복 조회를 제거했습니다. 과거 링크는 안내 페이지로 연결됩니다.
6. **개발자 중심 표현** — 제안 조건 JSON은 사용자용 문장으로, 해시 원문은 세부정보 안으로 옮겼습니다. AI 권한 선택은 읽기 쉬운 한국어 이름으로 표시합니다. 기술 관리자에게 필요한 원문은 상세 보기에서 유지합니다.
7. **검색 요청 충돌** — 검색어 입력 지연(350ms), AbortController를 사용한 선행 요청 취소, 오류 초기화·재시도, 활성 필터 표시·해제, 빠른 가격 조건, 결과 건수와 위치 표시를 추가했습니다.
8. **접근성** — 공통 입력 필드의 레이블 연결, 입력 설명과 필드 연결, 안내·오류 영역, 대화상자 제목·포커스 이동 및 Esc, 텍스트 대비·모바일 글씨 크기, 모션 최소화 설정을 보완했습니다.
9. **기본 브라우저 입력창** — 역제안, 관리자 매물 조치, 인수인계 보완, 취소·분쟁, 이미지 수정·삭제의 `window.prompt`/`window.confirm`을 일관된 대화상자로 대체했습니다.
10. **혼재된 UI 규칙** — 카드·입력·버튼 모서리, 보조 텍스트 대비, 여백, 단계·진행 표시를 통일하고 모바일 검색·거래·등록 화면에 대응을 추가했습니다.

## 운영 관련 제약

- 임시저장은 **현재 브라우저의 localStorage**입니다. 브라우저를 바꾸거나 저장 공간을 삭제하면 복구되지 않으며, 서버나 다른 기기에 자동 동기화되지 않습니다. 공용 기기 사용 시 임시본을 삭제해야 합니다. 로그인·비밀번호·토큰·원본 ZIP 내용은 저장 대상이 아닙니다.
- GitHub/ZIP 분석 연결 ID는 로컬 임시저장에서 복구하지 않습니다. 원본 소스가 별도로 연결됐는지 확인해야 합니다.
- 실제 브라우저 렌더링·접근성 자동 진단·모바일 실기기 테스트는 Replit 빌드 후 별도로 수행해야 합니다. 코드 수정만으로 UX 개선 효과를 입증할 수는 없습니다.
- 새 화면을 포함한 모든 거래는 여전히 시연 전용입니다. 결제·정산·소유권 이전이 일어나지 않습니다.
