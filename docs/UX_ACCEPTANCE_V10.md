# v0.10 UI/UX 수용 테스트 (실제 브라우저에서 실행)

여기는 실제 환경에서 **아직 실행하지 않은** 체크리스트입니다. 완료 후 결과를 기록하세요. 사용자에게 판매 대금 청구나 저작권 양도가 진행된다고 안내하면 안 됩니다.

## 매물 등록 (판매자 계정)

- [ ] 신규 매물에서 이름·설명·가격을 입력하고 새로고침 → 작성 내용 복구
- [ ] 등록 중 다른 단계 버튼 클릭 → 필수 항목 부족 시 해당 단계와 오류 안내
- [ ] 설명 29자/30자, 가격 0/정상, 포함 자산 공란/정상 등 경계값 검증
- [ ] GitHub/ZIP 자동 분석 → 기존 입력이 있는 경우 적용 전 경고 및 취소
- [ ] 자동 분석 후 새로고침 → 원본 연결 재확인 안내 및 명시적 선택
- [ ] 최종 미리보기 내용이 실제 매물 상세의 제목·가격·포함 자산과 일치
- [ ] 초안 저장 → 사진 등록 화면 → 내 매물 페이지 → 검토 요청
- [ ] 저장 완료 후 브라우저 임시본 삭제, 서버 매물에는 저장된 내용 반영
- [ ] 이미 수정된 매물과 예전 브라우저 임시본 충돌 시 자동 덮어쓰기 금지

## 탐색·상세 (구매자 계정 및 비로그인)

- [ ] 검색어 빠르게 변경 → 이전 요청 결과가 최신 결과를 덮지 않음
- [ ] 필터 활성 표시·개별 제거·전체 초기화·가격 빠른 선택
- [ ] 24개 초과 결과의 이전·다음 탐색 및 결과 개수 표시
- [ ] 네트워크 실패 시 오류·재시도, 0건 시 조건 초기화
- [ ] 상세 상단 제공 자산·운영 조건·위험·검증 표시
- [ ] 빠른 이동 링크 정상 이동, 기술 분석 미등록 시 안내 표시
- [ ] 매물 이미지·문의·구매 제안 등 기존 기능 정상

## 거래·관리 (판매자/구매자/관리자)

- [ ] 시연 제안·역제안 입력에서 전용 모달 표시·취소·입력 검증
- [ ] 양측 거래 조건 확인, 자료 전달, 구매자 검수, 완료에 따라 단계 변화
- [ ] 취소·분쟁 중 해당 상태와 다음 행동 표시
- [ ] 분쟁 접수·취소 동의·관리자 결정 시 확인 모달과 사유 필수값 동작
- [ ] 관리자 비공개 조치·파일 심사 사유 모달 동작
- [ ] 내 활동 알림·비공개 자료·AI 연결 설정 바로가기 정상
- [ ] 외부 AI 에이전트 토큰·승인 기능 기존대로 동작

## 접근성·반응형

- [ ] 360/390/768/1440px에서 주요 화면 가로 넘침 없음
- [ ] 모바일 필터 열기·닫기, 등록 단계 이동, 거래 진행표 확인
- [ ] Tab/Shift+Tab 포커스, 모달 내부 포커스 및 Esc 취소
- [ ] 화면 읽기 도구에서 폼 레이블·오류·거래 상태를 읽을 수 있음
- [ ] 색 대비 WCAG 2.2 AA 및 200% 확대 시 내용/기능 손실 여부 검사
- [ ] `prefers-reduced-motion` 활성화 시 과도한 전환 효과 없음

검증 중 발견된 오류는 화면·브라우저·재현 단계·네트워크 응답·로그를 함께 기록합니다.
