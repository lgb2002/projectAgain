# ProjectAgain v0.9 — 인수 후 개발 로드맵

## 목표
시연 인수인계 완료 이후 구매자가 실제 프로젝트를 이어가기 위해 수행할 작업을
난이도와 선행 조건별로 정리하고 개인 진행 현황을 관리하도록 지원합니다.

## 추가된 기능
- 공개 매물 상세 화면에 **예상 개발 로드맵** 표시: 4단계, 예상 작업 개수, 전문가 권장 작업,
  단계별 목록 및 선행 관계. 공개 저장소 주소, 소스 파일 경로, 비밀키는 노출하지 않습니다.
- 구매자용 **인수 후 로드맵 생성**: v0.8의 `DEMO_COMPLETED` 상태에서만 생성 가능.
  최초 생성 당시 매물·정적 분석 정보를 기반으로 작업 목록을 저장합니다.
- 작업별 난이도(쉬움/보통/어려움), 도움 수준(혼자 가능/도움 권장/전문가 권장),
  우선순위, 선행 작업, 근거 수준, 작업 순서, 완료 확인 사항 표시.
- 시작 전 / 진행 중 / 막힘 / 완료 및 개인 메모 저장.
- 선행 작업을 먼저 완료해야 다음 작업 진행/완료 가능; 후속 작업이 진행 중인
  경우 선행 작업을 무효화하는 변경도 제한.
- 개인 작업 최대 30개 추가, 기존 작업을 선행 조건으로 설정 가능.
- Markdown(.md) 다운로드: 현재 로드맵과 메모만 포함, 로그인·구매자 권한 필요.
- 기술 분석 요약/매물 정보가 변경되어도 기존 개인 진행 내역은 유지하고 변경 경고 표시.
- 변경 감사 기록 저장 (시연 작업 데이터로 표시).

## 유형별 구성

- 웹앱·SaaS·AI 에이전트·게임·모바일 앱에는 관련 기능/출시 점검을 추가합니다.
- DB 관련 기술을 감지하거나 판매자가 DB 사용을 고지하면 DB 이전 점검을 추가합니다.
- **콘텐츠·템플릿 유형에는 서버 실행·패키지 설치를 강제하지 않고** 편집 파일·콘텐츠 품질·권리·배포 패키지를 중심으로 생성합니다.

## 분석 원칙
**기술 분석은 정적 파일명·표준 매니페스트 기반입니다.** 판매자 정보와
정적 검사 결과를 구분하고 다음은 수행하지 않습니다.
- 판매자 소스코드 실행, 운영 환경 재현 또는 비밀키 수집
- AI 모델에 소스 전송 / 플랫폼 내 LLM 실행
- 권리·보안 적합성·사업 성공 가능성 인증
- 개발 시간·예산·완성 확률을 근거 없이 산정

`EXPERT`는 전문가 검토 **권고**로, 법률·보안·데이터·배포 관련
불확실성에 대한 안내입니다. 공식 자격 인증이나 유료 전문가 연결은 아닙니다.

## 접근권한
- 공개 예상 로드맵: 기존 매물 공개·시연 공개 규칙과 동일합니다.
- 개인 진행표: 인수 시연을 완료한 **구매자 본인**만 조회/수정 가능합니다.
- 판매자, 다른 구매자, AI 위임 토큰은 개인 진행표에 접근할 수 없습니다.
- 일회성 데모 거래 완료를 실제 결제나 소유권 이전으로 표현하지 않습니다.

## 추가 API
세부 요청/응답은 `docs/DEVELOPMENT_ROADMAP_API_V09.md` 참고.

## 배포와 호환성
마이그레이션 `0007_development_roadmap`에서 새 테이블 2개만 생성합니다.
기존 계정, 매물, GitHub/ZIP 원본, 거래/계약 데이터 구조를 변경하지 않습니다.
새 Secret은 필요 없습니다. 프론트엔드 소스는 다시 빌드해야 합니다.

## 알려진 제약
- 첫 버전은 일반적 복구·개발 절차를 제안합니다. 개별 함수 수준 분석이나
  실제 실행 성공 증빙, 실제 인수 완료 보증은 제공하지 않습니다.
- 로드맵은 생성 시 스냅샷입니다. 최신 소스로 자동 재생성하지 않아
  진행 기록이 보존되며, 변경이 감지되면 사용자가 직접 비교해야 합니다.
- 기술 분석이 없는 프로젝트는 판매자 입력 정보 기반 보수적인 기본 로드맵을 제안합니다.
- 외부 전문가 매칭 및 유료 연결, 실거래는 여전히 제공하지 않습니다.
