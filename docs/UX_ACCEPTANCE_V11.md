# ProjectAgain v0.11 실환경 UI·UX 합격 체크리스트

각 시나리오를 **데스크톱 1440px, 태블릿 768px, 모바일 390px/360px**에서 확인한다. 초보자용 판매자/구매자/관리자 계정 각각 사용한다.

## A. 알림 정확성

- [ ] 새 알림 1건 도착 → 헤더 배지 1 및 알림함 1.
- [ ] 알림 1건 읽음 클릭 → 배지가 바로 0이 되고 목록에서 읽음 표시.
- [ ] 알림 제목 클릭 → 읽음이 기록된 뒤 올바른 매물/문의/거래로 이동.
- [ ] 새로고침 후에도 읽음 상태 유지.
- [ ] 타 계정에서 기존 알림을 읽거나 수정할 수 없음.
- [ ] 읽지 않은 알림만 보기 및 해제, 모두 읽음 처리 정상.
- [ ] 100건 초과 알림에서 이전 알림 더 보기 및 미읽음 개수 정확.
- [ ] 읽음 요청 실패(네트워크 차단) 시 오류가 표시되고 가짜 성공 상태가 지속되지 않음.
- [ ] 탭에 다시 포커스했을 때 다른 곳에서 읽음 처리한 내역이 갱신됨.

## B. 전역 탐색·반응형

- [ ] 주요 메뉴 3개, 알림 및 설정 아이콘을 모두 찾을 수 있음.
- [ ] 판매자/구매자/관리자 딥링크 이동 후 뒤로 가기 동작.
- [ ] 360px에서도 헤더 메뉴를 열고 닫을 수 있고 메뉴가 겹치지 않음.
- [ ] 키보드 Tab/Shift+Tab 및 포커스 표시 정상.
- [ ] 글씨 대비/확대(200%) 및 화면 가로 넘침 확인.

## C. 매물 탐색·상세

- [ ] 검색 및 필터 선택 후 결과 일치, 상세 필터 접기/펼치기.
- [ ] 필터 초기화, 검색 결과 없음, API 실패 후 재시도.
- [ ] 매물 상세 구매 판단 요약을 첫 화면에서 파악 가능.
- [ ] 소개/기술·로드맵/문의/권리 탭 이동 및 콘텐츠 보존.
- [ ] 문의 공개·비공개 접근 권한, 거래 시연 안내 표시.
- [ ] 원본 ZIP·비공개 GitHub 저장소 경로가 공개 상세에서 노출되지 않음.

## D. 판매 등록 완주

- [ ] GitHub 공개 URL·비공개 저장소(설정 시)·ZIP·직접 작성으로 시작 가능.
- [ ] 자동 분석 결과 확인 후 수정; 단계별 필수 입력 검증.
- [ ] 새로고침한 임시본 복구 및 서버 버전 충돌 안내.
- [ ] 초안 저장 → `/sell/:id/complete`에 바로 진입.
- [ ] 이 화면에서 이미지·대표 사진·시연 URL·주요 기능 저장 가능.
- [ ] 저장하지 않은 시연 URL이 있을 때 검토 요청 버튼 비활성화.
- [ ] 사진 업로드 중 작성한 시연 URL 입력 내용이 사라지지 않음.
- [ ] 검토 요청 → `PENDING_REVIEW` → 관리자 승인 → 탐색에 노출.
- [ ] 초안 작성 도중 화면을 닫은 뒤 `내 프로젝트`에서 이어서 진행 가능.

## E. 업무·거래·관리자

- [ ] `내 프로젝트`에서 할 일, 판매·구매 상태와 보조 제안/문의 메뉴 발견.
- [ ] `비공개 자료` 진입 시 클릭한 매물이 미리 선택됨.
- [ ] 가격 제안·수락 → 조건 확인 → 자료 전달 → 구매자 확인 단계 정상.
- [ ] 진행 중 분쟁/취소는 바로 보이고 과거 기록은 접어서 볼 수 있음.
- [ ] 인수 후 개발 로드맵 생성 및 작업 진행·선행 작업 제약 정상.
- [ ] 관리자 검토 대기 목록·승인·반려, 신고 및 파일 심사 접근 유지.

## 합격 기준

모든 필수 버튼이 작동하고 기존 기능이 사라지지 않아야 하며, 사용자는 어디서 다음 작업을 하는지 별도 설명 없이 파악할 수 있어야 한다. 현재 이 문서는 **수동 테스트 지침**이지 자동 검증 완료 증빙이 아니다.
